Terminology

NVDA:

Non visual Desktop Access. A screen reader for Windows. It is free and donation-supported. Similar to Narrator and JAWS. Does not run on Mac or tablets. Current version: 2025.1.2

Control:

An item onscreen. A check box, an edit field and a list item are all controls. When you point to a file on your system it is a control. When you open a ribbon or menu, each item there is a control.

Focus:

This is where you are currently located in Windows. If you have a cursor, sometimes called an insertion point, where it points is the focus. If you have no cursor, your “keyboard focus” is a dotted outline around a control. If you were using a mouse, the focus would be at the point where you would click. NVDA attempts to automatically read the text, graphic or control that has focus. Your focus is usually on a specific character, if there’s a cursor or a specific control, if there is no cursor.

Preferences:

This is the menu for configuring NVDA. Most often you will choose Settings under the Preferences menu though other more advanced choices exist.

NVDA Key:

This is either Insert key or the caps lock key. Hold it down with another keystroke to issue an NVDA command.

Navigator Object:

This is where NVDA is currently pointing. The navigator object can often be pointed at the focus, but it also can be moved away to read other portions of the application.

Why Learn NVDA

if you know JAWS, you might need to use a computer where JAWS is not installed.

If you cannot afford JAWS, NVDA is free.

If you use magnification but occasionally want to read with speech, NVDA being free is ideal.

NVDA is not copy-protected; you can use it on any Windows machine.

If you are helping someone else with their computer, you can install and run it from a flash drive without affecting their PC at all.

If you work with sighted help, many find NVDA’s visual features make it easier to assist you.

If JAWS cannot read something you need to access, NVDA might be able to do it.

Plus, many folks find NVDA easier to learn than other screen readers.

Installing it

  1. Go to NVDA’s Website
  2. From the menu choose download.
  3. Ensure the radio button for “no donation is checked (unless you do wish to donate now) then hit the download button.
  4. The file you download is “nvda_2025.1.2.exe”.
  5. Locate and focus on the file in your downloads folder and press Enter to run it. You will be walked through its installation.

Basics

NVDA reads text and controls as you encounter them. If you edit a file, using the arrow keys will give the expected responses, for example, the control-right arrow reads the word on which focus has landed. AS you move through files and folders, the item on which you are focused is voiced.

If you tab between controls the one landed on is read. If you type text, you can set NVDA to read by characters, by words or by both or none. Press the NVDA key along with F2 to rotor between these settings. This is all you need to know to work with it in a very basic way. Explore your desktop, start menu and taskbar with NVDA. Try exploring Windows settings and editing a simple file with Notepad or Microsoft Word.

Success with NVDA occurs when you become proficient with Windows and the applications you intend to use. Windows learning resources are at the end of this document. Excerpts from David Kingsbury’s book on using Windows with a screen reader will be emailed to students.

Essential NVDA Keystrokes

Read the Title bar: NVDA+T. Use this to know what window has focus.

Read the current line: NVDA+L for laptop mode or NVDA+Up Arrow for desktop keyboard mode. Use this to know what line has focus.

Pull up the NVDA menus: NVDA+N. Use this to configure NVDA.

Read the current word: NVDA+Control+Period in laptop mode or NVDA+Numpad5 in desktop keyboard mode.

Read the current character: NVDA+Period in laptop mode or NVDA+Numpad2 in desktop keyboard mode.

Begin with Section 2 which is the quick start guide. Read up until section 2.5.

If you are running NVDA, you can get to this same guide by:

  1. holding the NVDA key and pressing N for its main menu.
  2. Arrow down to H for help.
  3. Arrow to your choice. You can read the full user guide, the Quick Start section of that guide or a keyboard reference. These pages open in your browser.

Accessing Preferences

  1. Hold the NVDA key with the letter N for the NVDA main menu.
  2. Select Preferences. Press ENTER.
  3. Select Settings, press ENTER.
  4. Seventeen Categories are available. Arrow to your choice then tab to the configuration items associated with your selected category.

For those with Older Computers

You can still download older versions of NVDA. Though Microsoft never recommends using older versions of Windows, the reality is you may be stuck with one or helping another user with one.

  • Windows XP: The last NVDA version supporting Windows XP is 2017.3. Subsequent versions, starting from 2017.4, no longer support Windows XP or Vista.
  • Windows 7: NVDA continued to support Windows 7 for several versions. However, as of 2025, NVDA has dropped support for Windows 7. The last version supporting Windows 7 is 2024.4.2, released in January 2025.
  • Windows 10 and Windows 11: The latest NVDA version compatible with both Windows 10 and Windows 11 is 2025.3, released on September 15, 2025. This version includes improvements in Windows 11, browse mode, Braille support , remote access and Microsoft Word.

For users on Windows XP or Windows 7, it’s important to note that these operating systems are no longer supported by Microsoft, which may pose security risks.
